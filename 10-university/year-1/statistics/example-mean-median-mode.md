# Mean, median, mode

## Key idea (one sentence)
Three different ways to describe the "centre" of a data set.

## Main points
- Mean = sum of values / number of values. Affected a lot by outliers.
- Median = middle value after sorting. Not affected much by outliers.
- Mode = most frequent value. A data set can have no mode or several.

## Definitions / formulas
- $\bar{x} = \frac{\sum x_i}{n}$

## Example
Data: 2, 3, 3, 5, 12
- Mean = 25 / 5 = 5
- Median = 3
- Mode = 3
The outlier 12 pulls the mean up, but not the median.

## Questions / I don't understand yet
- How do I find the median when n is even?

## Summary (write after the lecture, no looking)
The mean uses every value, the median uses position, the mode uses frequency. Use the median when there are outliers.
