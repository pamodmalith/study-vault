Association is the relation between 2 separate classes which establishes through their objects. composition and Aggregation are the 2 forms of association.

When an object of one class is created as a data member inside another class, it is called Has-A relationship. In other words, a relationship in which an object of one class has a reference to an object other another class or another instance f the same class is called Has-A relationship.

- Association
	- Aggregation
	- Composition
